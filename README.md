## التثبيت

### 1️⃣ استنساخ المستودع

```bash
git clone https://github.com/oody2010booa-creator/sumou-education-complex.git
cd sumou-education-complex
```

### 2️⃣ تثبيت المتعلقات

```bash
npm install
cd client && npm install && cd ..
```

### 3️⃣ إعداد متغيرات البيئة

```bash
cp .env.example .env
# عدّل الملف حسب احتياجاتك
```

### 4️⃣ إنشاء قاعدة البيانات

```bash
node server/scripts/initDb.js
```

## التشغيل

### تشغيل الخادم الخلفي (Terminal 1):

```bash
npm run dev
```

سيعمل على: `http://localhost:5000`

### تشغيل الواجهة الأمامية (Terminal 2):

```bash
npm run client
```

سيعمل على: `http://localhost:5173`

### الوصول إلى النظام:

افتح: `http://localhost:5173`

**بيانات التسجيل الافتراضية:**
```
البريد الإلكتروني: admin@sumou.edu
كلمة المرور: Admin123!
```

## الأدوار

### 👨‍💼 المدير (Administrator)
- إدارة كاملة للنظام
- إدارة المستخدمين والأدوار
- الوصول لجميع التقارير
- إدارة الإعدادات والسياسات

### 👨‍🏫 المدرس (Teacher)
- تسجيل الحضور
- إدخال الدرجات
- رفع الواجبات
- مراسلة الطلاب وأولياء الأمور

### 👨‍🎓 الطالب (Student)
- مشاهدة الدرجات والنتائج
- الاطلاع على الجدول الدراسي
- متابعة الحضور
- استقبال الإشعارات والواجبات

### 👨‍👩‍👧 ولي الأمر (Parent)
- متابعة أداء الابن/الابنة
- مشاهدة الدرجات والحضور
- متابعة الرسوم المستحقة
- استقبال الإشعارات

## نصائح التطوير

### تغيير كلمة السر الافتراضية

```javascript
// في ملف server/scripts/initDb.js
const hashedPassword = await bcrypt.hash('كلمة_سرك_الجديدة', 10);
```

### إضافة مستخدم جديد

```bash
curl -X POST http://localhost:5000/api/users \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{
    "email": "teacher@sumou.edu",
    "password": "Password123!",
    "name": "اسم المدرس",
    "role": "teacher"
  }'
```

## الدعم والمساعدة

في حالة وجود مشاكل:

1. تحقق من ملف `.env` وتأكد من الإعدادات
2. احذف مجلد `node_modules` وأعد التثبيت
3. افسح قاعدة البيانات: `rm database/sumou.db`
4. أعد إنشاء قاعدة البيانات: `node server/scripts/initDb.js`
